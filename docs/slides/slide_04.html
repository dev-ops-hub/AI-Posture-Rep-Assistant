How the App Works — User Flow

1
⚙️ Configure
Copy .env.example → .env

Set environment variables:
· CAMERA_INDEX (webcam)
· USER_WEIGHT_KG
· FITNESS_GOAL
· WORKOUT_MET

Optional:
· OPENAI_API_KEY
· VOICE_ENABLED
· VOICE_RATE / VOLUME
▶
2
🚀 Launch
Web mode (recommended):
uv run python -m webapp.app
Open http://localhost:5000

Desktop mode:
uv run main.py
Opens OpenCV window
Press q to quit
▶
3
🏋️ Track
Press ▶ Start

MediaPipe detects 33 3D body keypoints at 30 FPS

Rep FSM tracks:
STANDING → DESCENDING
→ BOTTOM → ASCENDING
→ rep counted

Spine angle monitored continuously
▶
4
🔍 Audit
Spine angle > 15° for > 2 s triggers snapshot

Frame → JPEG → Base64 → GPT-4o

Visual biomechanical diagnosis returned (1–2 sentences)

Voice agent speaks the correction tip

Max 2 API calls per session
▶
5
📊 Report
Press ⏹ Stop

GPT-4o-mini synthesises:
· Total reps & duration
· Calories (MET formula)
· Posture fault count
· Audit diagnostic notes

Report shown in browser with "Things to Improve" tips
🔊 Voice feedback runs throughout — rep milestones, posture alerts, form corrections, and session summary (all offline via pyttsx3)
