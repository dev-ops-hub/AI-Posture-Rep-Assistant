Problem & Solution

❌ The Problem
  • Solo gym-goers have no coach to count reps accurately
  • Poor squat form leads to serious knee & back injuries
  • Personal trainers are expensive and not always available
  • Existing apps give generic, delayed, non-contextual feedback
  • No affordable real-time AI coaching solution existed
→
✅ Our Solution
  • Automated rep counting via MediaPipe pose landmark tracking
  • Biomechanical spine-angle fault detection (>15° sustained for 2 s)
  • Posture snapshots sent to GPT-4o for visual biomechanical diagnosis
  • GPT-4o-mini generates personalised post-workout coaching summaries
  • Local pyttsx3 voice coaching — zero API cost, works offline
  • Flask browser panel: ▶ Start / ⏸ Pause / ⏹ Stop / ⏻ Quit
